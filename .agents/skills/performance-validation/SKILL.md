# 性能验证

## 定义实验

1. 明确假设、目标链路、负载形状、到达模型、数据量、并发度、持续时间和成功标准。
2. 记录应用构建身份、依赖版本、运行时限制、宿主机/容器资源及数据库/消息代理拓扑。
3. 隔离每次运行的数据和标识符；清理过程应有界、有序，并能处理中断。
4. 将环境预检与测量区间分开；环境受污染或结果不可比较时，不要采信该轮数据。

## 测量与诊断

- 跟踪投递量与接收量、终态结果、重试、残留记录、延迟分位数、吞吐、错误、积压和资源饱和度。
- 将应用指标与数据库等待、连接池、消息代理积压和 worker 利用率关联分析。
- 重复有代表性的测试并与同条件基线比较；解释波动和预热影响。
- 确认结论检查了完整业务结果，而不只是 HTTP 成功或进程退出码。

## 报告

记录命令、构建/revision、环境、负载、测量值、通过标准、清理结果和局限。将本地基准视为对比证据，不得当作生产能力保证。
