# 历史证据保留与技能提炼

仅在归档、拆分、提炼历史经验或全量文档／脚本转技能复核时加载；普通文档维护使用[文档治理入口](../SKILL.md)。目录与日期规则继续以[文档治理规范](../../../../docs/standards/document-governance.md)为权威，不在本参考另建规则副本。

## 原始经验保留与方法提炼

- 删除、归档或提炼前，核对正文中的故障前提、失败尝试、反例、方案弃选理由及原始测量；内容过时不等于没有证据价值，摘要承接不等于原始信息已无损保留。
- 原始记录保留日期/基线并标明不可直接执行；当前规则更新现行资产，可复用方法进入所属专项技能。三者互相引用，不把历史正文直接变成现行规约。
- 方法写清适用条件、调查步骤、反例/误判边界和验证证据；重复方法合并，已撤销方案只提取比较方法，不继承参数、严重度和PASS。
- 逐篇记录原路径、来源版本/哈希、保留状态、方法去向和不提炼理由。空模板、纯统计数据或重复总结不必各造一个技能，原统计口径和原始数值仍可保留。
- 历史LOC的物理/逻辑口径、排除目录、基线与dirty状态分别维护，不把跨口径数字连成质量或容量趋势。提炼后验证技能格式、链接、路由及现行规则冲突；不用历史测试通过证明新技能有效。

## 全量资料与脚本转技能的复核

固定Git可版本化文件清单并按真实路径去重，区分文本文档、契约/fixture、脚本/共享库、SQL迁移、测试和生成快照。逐文件记录来源哈希、内容扫描、路由与人工复核层级；不把关键词分类或全文读取宣称为逐行语义审查。

从真实参数解析、子命令、source/import、SQL和workflow验证文档所述方法；`--help`也先读实现，不执行整批入口获取帮助。数据表/CSV、历史PASS和重复候选清单不机械各造技能；现行事实、历史证据、可复用方法分别维护。优先现有职责，新技能必须解释与相邻技能的差异，并更新AGENTS、使用指南和可发现入口。
