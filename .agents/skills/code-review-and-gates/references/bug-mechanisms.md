# 代码 Bug 确认标准与失效机制

本页由 code-review-and-gates 统一维护，供普通 Bug 专项、变更审查和对抗式审查中的缺陷确认复用。完整规约清单由项目工程治理维护；本页不产生新的规约或风险等级。

## Bug 成立标准

必须能回答：当前代码位置、触发前提、执行路径、预期与实际差异、可观察影响和根因。并发问题提供交错步骤及事务/约束为何不能阻止；重试问题区分已失败、已成功与结果未知。源码已经确定因果但未动态复现时，明确标记“源码确认、运行未验证”；证据不足标记候选，不计为已确认 Bug。

设计上的至少一次投递、平台级跨租扫描、声明过的兼容/fallback 或性能取舍需核对自身不变量。只有有证据导致错误行为或违约时才列为缺陷；建议性设计改进和规约违反分别交付。

## 报告

- `BUG-*` 按实际影响定级：位置/行号、触发条件、预期与实际、影响、根因、证据层级、复现/验证命令、修复建议和状态。
- 已确认 Bug、待验证候选、已排除/合法反例分别列明；规约项只关联 `CONV-*`，不计入 Bug 汇总。
- 全量任务列模块/链路分母、已检查和未检查项。零发现表述为指定范围内未发现已证实 Bug，不能宣称所有路径没有风险。
- Bug 专项不要求整套规约检查；用户同时要求规约治理时使用项目工程治理的覆盖表和独立台账。只扫描时交付证据与建议，修复、编译/测试及环境操作按当前授权继续或保留明确边界。

## 失效机制与合法反例

本页只组织错误行为假设，不制定新的编码风格。按任务范围加载相关领域技能；全工程扫描对各适用机制记录当前入口、证据和未验证项。

| 机制 | 应追的错误路径 | 必须排除的误判或验证要求 |
|---|---|---|
| 计算、类型与输入 | 数值经 double/窄化丢精度，null/缺失/空串语义混淆，范围/分页/载荷边界失效，编码或序列化损坏。 | 给出具体输入与错误输出；字段同名或长度很大本身不是错误。历史[精度案例](../../../../docs/audit/backend-deep-scan-2026-06-19.md)只作线索。 |
| 状态机与统计 | 非法转换、终态复活、dry-run 分类遗漏、重复 report 重计数、部分/总数不守恒、结果版本选错。 | 对当前领域枚举、SQL 分类、前态/CAS、实际状态和计数逐项对账；专项策略不强行归为共享生命周期。 |
| 并发与租约 | 先读后整行覆盖、双 claim/finish、source task 多条 dead letter 并发提交、旧 owner/leader 写入、续租等待拖过窗口、ABA。 | 给出交错时序、事务隔离、CAS 返回值、唯一约束和 fencing 身份；不能仅凭没有 version 字段认定丢更新。 |
| 事务、代理与线程上下文 | 自调用绕过代理、REQUIRES_NEW 回滚范围错误、after-commit 失败丢补偿、异步 RLS/MDC/数据源上下文缺失或残留。 | 沿真实调用和提交点核对；注解排列和 ThreadLocal 出现不自动证明错误。见[事务方法](../../worker-pipeline-review/references/historical-methods.md)。 |
| 幂等、重试与未知结果 | 业务已提交响应丢失后重做，重试换幂等键，回执/dedup 过早归档，失败回退重跑已成功业务。 | 以稳定业务身份、receipt/ledger 和真实副作用对账；至少一次消息重发本身合法，未取得结果保持 unknown。 |
| 调度与依赖 | 业务日/时区/DST、misfire、catch-up、pause/resume、门禁等待、Job/Workflow 同日跨日依赖或 Join 决策错误。 | 追真实时间/配置版本/请求与实例身份，保持各用例自己的语义；用边界及相似合法时间作反例。调用 `scheduler-correctness`。 |
| 批量、消息与 Worker | 批量请求/响应错项、乱序归因、逐项回滚/ack 丢失，Kafka offset 提前提交，队列准入/背压或 lease/report 生命周期断裂。 | 按 task/claim 身份逐项对账；批量传输不等于批量业务事务。调用 `worker-pipeline-review`、`sdk-contract-governance`。 |
| SQL、Mapper 与迁移 | 绑定字段错位、record/resultMap 不匹配、错误 JOIN/过滤/排序/分页、SQL 方言或迁移执行失败、归档丢数据。 | 看实际调用参数、返回映射、DDL 与约束；未测计划不能报告性能收益，空库迁移成功不等于升级兼容。 |
| 配置导入与生效 | 声明/保存了配置但分支不消费，默认值/profile/env 漂移，提交后未失效缓存，更新覆盖在途快照，撤销密钥仍被使用。 | 分开新任务与在途任务、preview/apply/发布/回执；追具体消费者及真实版本。调用 `configuration-governance`。 |
| API、权限与租户 | 路径/方法/字段不兼容、校验失效、错误码/HTTP 不符、跨租/对象归属绕过、敏感字段外泄、Locale 错误渲染。 | 追认证主体到目标对象及持久化副作用；平台后台全租扫描或内部协议不套 Console envelope 可是合法边界，需当前证据。 |
| 资源、取消与恢复 | 连接/流/文件/线程未释放，池/队列无界，取消后副作用继续，停机丢任务，checkpoint 与文件边界不一致。 | 核对真正所有者与关闭传播；wrapper 由调用方关闭、daemon 退出等要按实际 in-flight 语义判断。追失败/超时/取消路径。 |
| 多语言及滚动兼容 | SDK 字段、类型/null、错误/offset 处置、claim/renew/report 身份或真实 transport 行为不一致，旧新版本共存断链。 | fixture、构建包与真实网络证明范围分别报告；Java 通过不能外推其他语言，协议预期独立于单个实现。 |
| 异常、事件与可用性 | catch 后错误返回成功、配置关闭却记触发成功、告警提前 resolved、投递失败写成功回执、恢复丢通知。 | 追用户结果/业务状态/实际发送与最终回执；窗口 Counter 消失或日志无报错不能证明恢复。调用 `observability-governance`。 |
| 构建、装配与符号绑定 | 类/包冲突、FQN 缩短绑定错误、重载遮蔽、Lombok/record 生成入口缺失、Bean 缺失或配置未装配。 | 代码缺陷与本机 JDK/可选依赖/仓库网络问题分开；未实际运行编译或启动时准确标明验证层级。 |
